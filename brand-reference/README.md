# Referência da embaixadora da marca

`embaixadora-oficial.png` é a foto oficial da modelo/embaixadora da Alna Commerce,
fornecida pelo cliente. **Não é usada pelo site** (não fica em `src/`, não é
publicada no build) — serve só como referência de identidade para gerar novos
banners com IA.

Ao gerar qualquer novo banner/imagem com essa modelo, use este arquivo como
referência de rosto (upload via Higgsfield `media_upload`), nunca uma imagem
já gerada por IA anteriormente — evita o "efeito telefone sem fio" em que
cada geração se afasta um pouco mais do rosto real dela.
